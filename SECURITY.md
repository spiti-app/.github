# Security

Please don't report security issues in public issues.

Use GitHub's [private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on the affected repo: open its **Security** tab and choose **Report a vulnerability**. Include the steps to reproduce, the affected version and the impact.

Only the latest release of Spiti and each official package gets security fixes.
