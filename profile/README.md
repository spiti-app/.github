# Spiti

An open-source personal workspace that runs on your Mac. Add plugins for the tools you need, or have Claude Code or Codex build them for you, and connect them to the services you already use. Your Mac hosts everything; your iPhone, iPad and other Macs reach it privately over Tailscale.

- **Yours.** Your Mac is the server. No Spiti account, no Spiti cloud.
- **Built by you and your agents.** Every feature is a plugin, made to be written by an agent from one prompt.
- **Native where it counts.** Command center, menu bar, floating windows, shortcuts and notifications on the Mac; a native app on iPhone and iPad.
- **Safe by default.** Plugins ask before using anything sensitive.

Spiti is in early development. The core and website repos open with the first release, under Apache-2.0.

Every official plugin and integration lives here as its own repo, named after its id.
